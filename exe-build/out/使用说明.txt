==================================================
  科目一模拟考试 · 便携版（免安装）
==================================================

【一、运行要求】
  1. Windows 10 / 11（64 位）
  2. .NET Framework 4.8（Win10/11 一般已内置）
  3. Microsoft Edge WebView2 Runtime：
     - Win11 已内置，无需额外安装；
     - Win10 若提示缺少，请在微软官网搜索并下载
       "WebView2 Runtime (Evergreen Standalone Installer)" 安装即可。

【二、使用方法】
  1. 保证「科目一模拟考试.exe」与「WebView2Loader.dll」
     两个文件放在同一个文件夹里（缺一不可，切勿只拷贝 exe）。
  2. 双击「科目一模拟考试.exe」即可开始做题。

【三、数据存储（仅保存在本机）】
  - 考试成绩、错题本、考生信息等保存在：
      %LOCALAPPDATA%\Km1Exam\webview-data\
  - 删除上面这个文件夹即可清空全部本地数据。

【四、常见问题】
  - 双击无反应 / 提示"初始化失败"：
      先确认已安装 WebView2 Runtime（见第一条）。
  - 需要排查时，查看日志：
      %LOCALAPPDATA%\Km1Exam\app.log
  - 首次启动会短暂解压题库到
      %LOCALAPPDATA%\Km1Exam\app\ ，属正常现象。

【五、说明】
  - 本程序为单文件网页（2085 题题库，含图片）封装的原生窗口客户端，
    数据全部存在本机，不上传网络。
  - 部分杀毒软件可能对自编译 exe 误报，可将其加入白名单。
