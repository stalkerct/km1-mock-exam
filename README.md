# 科目一模拟考试系统

## 使用方法

**双击打开 `科目一模拟考试.html` 即可**（用 Edge / Chrome 浏览器，无需安装任何东西）。

## 功能

| 模块 | 说明 |
|------|------|
| 模拟考试 | 100 题（判断 40 + 单选 60）· 45 分钟倒计时 · 90 分合格 · 考中不显对错 · 与真实考试规则一致 |
| 考试机仿真 | 考生登录核验 → 考试须知 → 答题（自动跳题/可回改）→ 答题卡方格阵 → 交卷确认 → 成绩单（合格印章）|
| 错题回顾 | 交卷后逐题展示：你的答案 vs 正确答案 + 解析 |
| 错题本 | 自动收集错题（含答错次数），支持错题重练，答对自动移出 |
| 成绩历史 | 历次分数/用时/错题数记录 + 场次/平均分/最高分/通过率统计 |
| 键盘操作 | A/B/C/D 或 1-4 选答案，← → 切题（模拟考场小键盘）|

## 题库

- **2085 题**（判断 1075 / 单选 1010），其中 **747 道图片题**（交通标志、信号灯、仪表板指示灯、行车场景等）
- 来源：公开驾考题库整理（shiroha-quiz 项目 GPL-3.0 + 驾校宝典公开题目），合并去重、剔除 2022 记分新规前易过时的记分/审验类旧题
- 图片从原版题库文档中逐题位置匹配提取，经压缩内嵌（HTML 单文件约 7.8MB，双击即用）
- **19 个知识分类**，组卷时按分类占比加权抽题（试卷分布 ≈ 题库分布，实测最大偏差 1.3%），单选选项随机洗牌
- 每套卷图片题约占 27~48 题（与真实考试图题占比相当）
- 非官方题库，仅供练习；法规更新请以现行规定为准

## 数据存储

成绩与错题保存在浏览器 localStorage，同一浏览器持续生效；清空浏览器数据会清除记录。

## 重新构建（可选）

修改题库或界面后运行：

```
node research\build.js
```

- `app-template.html`：界面模板（`__BANK_DATA__` 为题库占位符）
- `research/bank-final.json`：最终题库（含 base64 图片）
- `research/build-final-bank.js`：题库构建脚本（解析 docx → 匹配图片 → 压缩 → 合并去重）
- `research/km1-stream-parsed.json`：docx 全量 1812 题解析结果（题目-图片按位置精确对应）
- `research/img-compressed/`：724 张压缩后的题目图片
- `research/parse-stream.js` 等：各处理环节脚本
